# 世界的声音（astrbot_plugin_ear）

让只会读文字的模型**听得见声音本身**——不是把语音转成文字，而是听语气、听停顿、听背景，
再把这些感受交给主模型。人格、记忆、说话方式都不变，只是多了一只耳朵。

---

## 它是怎么"听"的

```
QQ 语音 / 抖音作品
   ↓ ffmpeg 转 16k 单声道 wav（超过 60 秒截断）
   ├─ ① 声谱图：ffmpeg 把声音画成一张图（横轴秒、纵轴频率）
   └─ ② 听觉模型：听一遍，写成**第一人称的听感**
   ↓ 两样一起塞进临时上下文（不进历史、不破坏前缀缓存）
   ↓ 主模型用自己的语气回你
```

主模型（DeepSeek 这类）本身收不了音频，只会看到一句 `[Audio]`。
插件替它听，再把"听到的东西"递过去；它读到的是体验，不是数据。

**为什么是"第一人称"**：让它读到的是

> 声音轻轻的，像刚从被窝里爬起来，尾音往下掉，没力气，但挺温柔。
> 中间那句「走走吧」拖了半拍，像忍着笑又怕吵醒谁。

而不是

> 对方语气平静，语速中等，音量稳定。（← 实验报告，读起来不像听见了）

---

## 能听出什么

| | 语音转文字（STT） | 世界的声音 |
|---|---|---|
| 信息 | 一串字 | **语气 / 语速 / 停顿 / 尾音走向 / 背景声 / 声谱图** |
| "他在笑" | ❌ | ✅ |
| "声音在抖" | ❌ | ✅ |
| 背景在放歌 | ❌ | ✅ |

---

## 两个入口

**① QQ 语音**：收到语音时自动听，只在私聊、只对主人生效。

**② 抖音作品**：可截取播放器真实音频轨（不是转录），听讲解、听 BGM、听情绪；
声谱图会在下一次模型调用时补进去，让它"看到"声音的形状。
需要配置一个已登录抖音的浏览器调试地址（`douyin_cdp_url`）。

---

## 支持的模型 / 供应商

要求：OpenAI 兼容的 `/chat/completions`，且支持 `input_audio` 音频输入。

| 供应商 | `base_url` | 可用模型（实测） |
|---|---|---|
| 阿里云百炼 DashScope（默认） | 留空 | `qwen3-omni-flash`、`qwen3.5-omni-flash` |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | `Qwen/Qwen2.5-Omni-7B` 等 |
| 其他 OpenAI 兼容端点 | 填对方地址 | 任何支持音频输入的模型 |

DeepSeek 收不了音频，只能当"脑子"，不能当耳朵。

## 配置项

| 配置项 | 说明 | 默认 |
|---|---|---|
| `enabled` | 总开关 | `true` |
| `base_url` | 听觉模型接口地址，留空 = DashScope | 空 |
| `api_key` | 对应供应商的 Key | 空 |
| `model` | 听觉模型 | `qwen3-omni-flash` |
| `only_owner_private` | 只在私聊、只对主人生效 | `true` |
| `owner_qq` | 主人 QQ 号（留空则退化为仅管理员） | 空 |
| `daily_limit` | 每天最多听几次（0 = 不限） | `300` |
| `douyin_enabled` | 抖音听觉开关 | `false` |
| `douyin_cdp_url` | 已登录抖音浏览器的调试地址 | 空 |

## 可视化视图

插件带一个视图页，在 WebUI 里可以：

- 改配置（开关、Key、模型、额度、抖音）
- 查看**听取记录**：时间、时长、来自谁、听到了什么
- 一键清空

记录存在插件数据目录 `history.jsonl`，最多保留 200 条。

## 依赖

- **ffmpeg**（必须）：转码 + 生成声谱图，`apt install ffmpeg`
- Python 侧只用标准库 + AstrBot 自带依赖，无需额外 pip 安装

---

## 安全与成本

- 只有**带语音的消息**才触发，纯文字不消耗额度
- 默认只在**私聊、发送者是主人**时生效
- 单条最长处理 60 秒
- `daily_limit` 防意外刷爆（默认 300）
- Key 只存配置，不写日志、不随包分发
- 下载 / 转码 / 调模型全部走 `asyncio.to_thread`，不阻塞事件循环
- 声谱图用完即删

---

## 已知限制

- 需要一把支持**音频输入**的 key（DeepSeek 不行）
- 只在收到语音那一刻听一次，不能"一直听"
- 不做声纹识别（听不出是谁在说）
- 背景音乐能听出"有音乐、什么感觉"，通常说不出曲名
- 声谱图是给模型"看个形状"的，不是精确频谱分析
- 抖音听觉依赖那个浏览器保持登录
